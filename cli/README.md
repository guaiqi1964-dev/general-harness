# CLI 模式

终端模式已内嵌于 bin/gh.exe（gh 或 gh chat），无需单独文件。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/model <名称>` | 切换当前模型（支持 `厂商/模型`、裸模型名与别名，如 `fast` / `smart` / `long`） |
| `/models` | 列出可用模型（云端与本地 GGUF） |
| `/search [on\|off\|status]` | 联网检索开关；不带参数等于 `status`。开关仅影响当前会话，配置文件里 `search.enabled=false` 时无法开启 |
| `/web <检索词>` | 单次联网检索并打印编号来源，不影响会话开关 |
| `/key list` | 列出厂商及其 Key 配置状态（只回显掩码，不打印完整 Key） |
| `/key set <厂商> <Key>` | 写入该厂商的 Key 到 `keys.yaml`，**立即生效**（热加载，无需重启引擎） |
| `/clear` | 清空当前会话上下文 |
| `/help` | 显示帮助 |
| `/exit`、`/quit` | 退出 |

## 说明

- 回答下方若带来源，会以 `[序号] 标题 — URL` 的形式打印。
- 联网检索的隐私红线：发给搜索服务的是引擎本地提取的检索词，不含问题原文（详见根目录 README 的「联网搜索」章节）。
- 当前终端模式只打印思考指示符「…」与正文，**不**单独渲染 `reasoning_content` 思考段。
