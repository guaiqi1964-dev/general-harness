# CLI 模式

终端模式已内嵌于 `bin/gh.exe`（`gh chat`），无需单独文件。v0.3.3 起，CLI 的能力
与桌面 GUI 基本对齐：模型切换、多轮对话、流式输出、思考折叠、联网检索、用量统计、
密钥管理、配置查看、中断当前生成。

## 启动

```bash
gh chat                        # 交互模式（终端）
gh chat --repl                 # 强制交互模式（用于脚本 / 重定向场景）
echo "用一句话解释 TCP" | gh chat   # 管道模式：一次性输出，纯正文
```

管道模式下 stdout 只输出回答正文，可直接重定向或接管道：

```bash
echo "总结这段日志" | gh chat > answer.txt
```

## 命令

| 命令 | 说明 |
| --- | --- |
| `/model <名称或序号>` | 切换模型；序号对应 `/models` 的输出（如 `/model 2`） |
| `/models` | 列出云端与本地 GGUF 模型，`▸` 标记当前模型，`[视觉]` 标记支持图片的模型 |
| `/think [on\|off]` | 思考过程展开 / 折叠（默认折叠，只显示 `💭 思考中… N 字`） |
| `/search [on\|off\|status]` | 联网检索开关；不带参数等于 `status`。引擎侧 `search.enabled=false` 时无法开启 |
| `/search list` | 列出搜索后端与就绪状态（缺环境变量等原因会直接说明） |
| `/search backend <名>` | 切换搜索后端（仅本次运行生效，不写回配置文件） |
| `/web <检索词>` | 单次联网检索并打印编号来源，不影响会话开关 |
| `/key` | 列出厂商及其 Key 配置状态（只回显掩码；占位符 Key 会明确标注） |
| `/key <厂商> <Key>` | 写入 `keys.yaml`，**立即生效**（热加载，无需重启引擎） |
| `/key <厂商> -` | 清除该厂商的覆盖 Key，回退到插件配置 |
| `/usage [1d\|7d\|30d\|all]` | 用量统计（默认 `1d`），按时间桶画方块条形图，只显示有流量的桶 |
| `/usage conv` | 最近会话明细（会话 ID / 模型 / tokens） |
| `/config` | 查看当前生效配置：监听、限流、鉴权、模型、别名、联网检索、Agent、各文件路径 |
| `/history` | 查看本次会话轮数与最近几条对话摘要 |
| `/clear` | 清空当前会话上下文 |
| `/cls` | 清屏（保留对话历史） |
| `/help` | 分组显示帮助 |
| `/exit`、`/quit` | 退出 |

## 交互细节

- **提示符带状态**：`你 [deepseek-chat | 联网:关] ›`，模型与联网开关一眼可见。
- **流式生成**：正文逐块输出；结束时打印 `⏱ 0.9s · 输出 49 字`。
- **思考折叠**：终端里原地刷新一行 `💭 思考中… N 字`（节流到每 120ms / 每 5 字，
  不会刷屏）；`/think on` 后以灰色完整展开。重定向到文件时只输出一行汇总。
- **联网**：开启后先显示 `⏳ 正在检索…`，拿到结果显示 `📡 已检索到 N 条来源`，
  回答末尾打印编号来源卡片（`[1] 标题` + URL）。
- **Ctrl+C**：生成过程中按 Ctrl+C 只中断当前请求（保留已输出的正文并提示
  `⏹ 已中断`），不会退出程序；空闲时按才退出。
- **多行输入**：行尾加 `\` 续行，方便粘贴整段内容。
- **错误提示**：401 会提示用 `/key <厂商> <密钥>`；429 / 连接错误会给出对应排查方向。
- **颜色**：仅在真实终端着色；设置 `NO_COLOR` 或重定向输出时自动关闭。

## 说明

- 回答下方若带来源，会以 `[序号] 标题 — URL` 的形式打印。
- 联网检索的隐私红线：发给搜索服务的是引擎本地提取的检索词，不含问题原文
  （详见根目录 README 的「联网搜索」章节）。
- 本地 GGUF 模型（`local/xxx`）只返回元数据摘要，不做推理。
